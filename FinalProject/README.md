# Dataset:
Acute Leukemias of Ambiguous Lineage (TARGET GDC, 2025) </br>

The Acute Leukemias of Ambiguous Lineage dataset has:
- [Acute] Lymphoid leukemia, NOS (233 samples)
- [Acute] Myeloid leukemia, NOS (15 samples)
- [Acute] Leukemia, NOS (3 samples). 
  - NOS means "Not Otherwise Specified".  


# Objective
Determine the difference between Acute Myeloid Leukemia and Acute Lymphoid leukemia.
